# Presentación

`Generacion-Solar-Guatemala.pptx` — 11 diapositivas con notas del orador en cada una.

| # | Diapositiva | Qué defiende |
|---|---|---|
| 1 | Portada | **Completar con los nombres del equipo** |
| 2 | Qué había que resolver | Alcance y qué calcula el sistema por su cuenta |
| 3 | Arquitectura | Por qué Filament para capturar y Blade propio para analizar |
| 4 | Modelo de datos | Las seis tablas y por qué no se almacenan valores derivados |
| 5 | Tablero nacional | RF-11 y RF-12 |
| 6 | Mapa interactivo | RF-13 y las decisiones de codificación visual |
| 7 | Alertas | RF-14 y el caso borde del 80% exacto |
| 8 | Proyección | RF-15, el método y su precisión histórica |
| 9 | API REST | RF-16 y la documentación generada desde el código |
| 10 | Uso de IA | Qué decidió el equipo y qué hubo que corregirle |
| 11 | Cierre | Métricas del sistema y **URLs por completar** |

Antes de presentar hay que llenar dos cosas: los nombres del equipo en la portada y las URLs de la
aplicación y del repositorio en la última diapositiva.

El guion sugerido reserva cinco o seis minutos para la demostración en vivo, entre las diapositivas 4
y 9: crear una generación por debajo del umbral y ver aparecer la alerta sola es el momento más
convincente.
